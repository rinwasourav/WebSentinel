# Security policy

WebSentinel is pre-release (0.1.x); no release is currently guaranteed supported. Report vulnerabilities privately to the repository owner through GitHub's private vulnerability reporting when enabled. Do not include credentials or live target data in reports.

WebSentinel is intended only for systems with explicit authorization. The passive MVP does not exploit vulnerabilities, guess credentials, submit forms, or perform unrestricted crawling. Its scope and IP protections reduce accidental requests but cannot guarantee zero impact or eliminate every network-routing risk. Local isolation does not isolate a target server. Reports may contain sensitive target metadata; store and share them carefully.
