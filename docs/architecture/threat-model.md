# Initial threat model

Assets: operator authorization, target scope, assessment evidence, local report/database contents, and user credentials. Threats include scope bypass, unsafe redirects, DNS rebinding to private infrastructure, credential leakage, malicious response content in reports, runaway requests, and inaccurate findings. Controls include exact allowlists, per-hop DNS/IP validation, pinning the connection to a validated IP, checking the connected peer before sending HTTP bytes, an authorization gate, bounded request/rate/time settings, no raw body retention, evidence redaction, escaped HTML, and safety tests. Residual risk includes network routing or NAT behavior outside the scanner, server-side effects from even GET requests, and scanner false positives; do not treat local isolation as target isolation.
